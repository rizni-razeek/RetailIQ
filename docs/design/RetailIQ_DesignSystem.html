Quick Reference

✓ Do
  • Use var(--token-name) for every value
  • Use JetBrains Mono for all numbers in tables
  • Use DM Serif Display only for headings and logo
  • Use semantic colours only for their intended purpose
  • Toggle theme via data-theme="dark" on html
  • Keep one primary button per section/page area
  • Show variance numbers in red or green using delta classes
  • Use card-alert with a left border for stock warnings
✗ Don't
  • Don't hardcode hex colours anywhere in components
  • Don't use Inter, Roboto, or system-ui — they scream generic
  • Don't use warning yellow for non-warning decoration
  • Don't use blue or purple as the primary accent colour
  • Don't mix font families inside the same text block
  • Don't write raw px spacing — always use --space-n
  • Don't use more than 2 badge colour variants in one row
  • Don't use cold blue-grey neutrals — use the warm green-tinted set
